# FlowDesk dashboard enhancement

## Dashboard
- Expand the existing Overview into a practical dashboard with a greeting, current date, and quick-start tool cards.
- Add compact productivity metrics for generated drafts, planned tasks, and research briefs.
- Add a recent activity area and a focused “today” panel using local demo data only.
- Keep all cards actionable so users can open the relevant FlowDesk tool directly.

## Constraints
- Preserve the existing black, charcoal, and yellow design.
- Keep the app fully local with no backend, accounts, or login.
- Maintain responsive desktop and mobile layouts.
